# Kanzi constituency reanalysis

## Scope

This checkpoint reconstructs the complete published sentence-type counts from Savage-Rumbaugh et al. (1993), combines them with the reversible-pair reanalysis of Schoenemann (2022) and the NP-coordination reanalysis discussed by Truswell (2017) and later reviews, and asks whether the evidence identifies a general hierarchy deficit or a narrower coordination/constituency deficit.

## Core counts

Kanzi:
- all scored trials: 467/653 correct = 0.7152
- blind trials: 307/415 correct = 0.7398
- Type 2B (give/show X and Y to animate A): 7/21 all = 0.3333
- Type 2B blind: 7/19 = 0.3684

Type 2B versus all other blind trials: OR = 0.1867, Fisher two-sided p = 0.000531.

Pairwise blind comparisons:
- Type 2B vs Type 2A single-object give/show: OR = 0.1620, p = 0.00312
- Type 2B vs Type 5C embedded-location/relative-clause-like: OR = 0.1728, p = 0.00699
- Type 2B vs Type 3 action-object-instrument: OR = 0.1313, p = 0.000830
- Type 2B vs Type 5B go-and-get: OR = 0.1276, p = 0.000992
- Type 2B vs Type 6 causative/pretend nested-role construction: OR = 0.2917, p = 0.228 (small n)

## Reversible-order evidence

Schoenemann's 20 reversible sentence pairs:
- 14 pairs both correct
- 5 pairs one member correct
- 1 pair both wrong

This strongly supports sensitivity to linear order/thematic-role assignment in this individual.

## NP coordination

Truswell identified 26 NP-coordination requests and excluded 8 confounded cases. In the remaining 18:
- 4 fully correct = 22.2%
- 9 ignored the first NP
- 5 ignored the second NP

Against a 71.5% whole-corpus benchmark, 4/18 is extremely low (two-sided binomial p about 2.08e-5). Against the 1/3 success rate predicted by a simple no-grouping heuristic, however, 4/18 is not unusual (two-sided p about 0.454).

## Identification

There is a sharp empirical dissociation between strong reversible linear-role performance and poor NP coordination.

However, the evidence does not identify a blanket inability to process hierarchy:
- Type 5C blind: 27/35 = 77.1%
- Type 6 blind: 6/9 = 66.7%
- Type 3 blind: 40/49 = 81.6%
- Type 5B blind: 32/39 = 82.1%

The original authors explicitly interpreted Type 2B difficulty as potentially reflecting short-term-memory/list burden. Truswell's constituent-grouping account is a strong alternative explanation. The existing task does not cleanly separate those mechanisms.

## Conservative verdict

`KANZI_LINEAR_ROLE_ORDER_SUPPORTED__NP_COORDINATION_TARGETED_DEFICIT_REPRODUCED__GENERAL_HIERARCHICAL_INCAPACITY_NOT_IDENTIFIED__MEMORY_VS_CONSTITUENCY_MECHANISM_UNRESOLVED`

The strongest defensible statement is that Kanzi shows a targeted deficit on NP coordination relative to otherwise strong spoken-command comprehension and reversible-order performance. This is evidence relevant to constituent grouping, not a species-level upper bound on bonobo hierarchical cognition.
